# WatchValue IL — MVP

Israeli luxury-watch pricing platform.

## Included
- Hebrew RTL landing page
- Search by brand/model/reference
- Brand coverage grid
- Market price table
- Reference detail pages
- Price-history chart mock
- Current / Discontinued status
- 7-day free trial pricing modal
- $14.99 monthly / $149 annual pricing
- Express backend + PostgreSQL schema

## Important
All market prices in this MVP are placeholders for product/design testing only. They are not live market valuations.
