# Decision Log

## 2026-09-24
- Product name is temporarily "WatchValue IL"; name may change later.
- Product is Israeli and Hebrew-first.
- Scope is liquid luxury-watch brands only, but all materially traded references inside those brands.
- Include current, discontinued and materially traded limited editions.
- Reference-level catalog, not generic model-level catalog.
- 7-day free trial.
- USD 14.99 monthly subscription.
- USD 149 annual subscription.
- Subscription is the primary MVP monetization model.
- Web first; no native iOS/Android app during MVP.
- Avoid paid watch-data API during MVP where legally usable alternatives suffice.
- System should be highly automated and require minimal owner day-to-day work.
- Railway + PostgreSQL + GitHub are the target persistent architecture.
